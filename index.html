Project Spotlight

CLARITY

Accessibility Platform for Deaf & Hard-of-Hearing Individuals

Overview

CLARITY is a web-based accessibility platform designed to improve communication through AI-assisted tools such as live captioning, transcript management, and speech-based interaction.

The Challenge

Many everyday conversations depend on spoken communication. This creates challenges for deaf and hard-of-hearing individuals in classrooms, hospitals, and public spaces where important information may only be delivered verbally.

My Approach

CLARITY explores how AI can improve accessibility by combining speech recognition, AI-generated summaries, and communication tools into one platform.

Key Features

  • Real-time Live Captioning
  • AI-generated Transcript Summary
  • Save Conversation History
  • Translation Support
  • Text-to-Speech Responses
